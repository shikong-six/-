# 踩坑记录：独立脚本 import db.ts 连不上 MySQL

## 问题现象

- 写了个一次性脚本 `seed-test-data.ts`，`import pool from './src/services/db'`，一运行就报：

```
Access denied for user 'root'@'localhost' (using password: NO)
```

- 明明 `npm run dev` 起的服务连库完全正常。

## 问题原因

读 `.env` 的代码在 `src/config.ts`（里面调 dotenv），而它是被 `app.ts` 用 `import './config'` **最先加载**的，别的模块都假定环境变量已经就绪。

独立脚本没有走 `app.ts` 这条链，直接 import 了 `db.ts`——此时 `process.env.DB_PASSWORD` 等全是 undefined，连接参数（含密码）是空的，MySQL 自然拒绝。

## 解决方法

独立脚本第一行先加载 config，再 import 任何业务模块：

```ts
import './src/config';   // 必须先加载，读取 .env
import pool from './src/services/db';
```

## 经验总结

- 这个项目的隐式约定是"app.ts 最先 import config"，任何绕过 app.ts 的入口（脚本、测试）都要自己补上这条链。
- 报 "using password: NO" 优先怀疑环境变量没加载，而不是密码真的错了。
